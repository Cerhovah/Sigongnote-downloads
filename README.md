# 시공노트 설치 파일

실제 사용 주소: https://sigongnote-api.onrender.com/

앱 설치 안내: https://sigongnote-api.onrender.com/install

이 저장소는 서명된 Android APK와 Windows 설치 파일을 배포합니다. 사용자 자료나 로그인 비밀, 소스 코드는 포함하지 않습니다.

네이버 로그인은 서비스의 공급자 설정 완료 후 사용할 수 있습니다. 설치 안내의 연결 상태를 먼저 확인하세요.

기존 Android 앱은 삭제하지 않고 업데이트하세요. Windows ZIP은 새 폴더에 풀고 Sigongnote.Windows.exe를 실행합니다. SHA256SUMS.txt와 BUILD.json으로 파일과 빌드 기준을 확인할 수 있습니다.
